txflow – Transaction Flow Experiments

Rust WebAssembly Leios Claude

Describe a Cardano transaction flow in plain words and run it on the Leios Musashi test network. The model writes a declarative spec (chains, double spends, competing chains), the page checks it with the same Rust code compiled to WebAssembly and draws the UTxO graph. A run funds the experiment, signs every transaction, sends each to its relay in Frankfurt, Virginia or Tokyo on schedule, and shows when it reached each mempool and which block it landed in. Specs carry no transaction ids, so an experiment reruns on the next node build. Eine Cardano-Transaktionsfolge in Alltagssprache beschreiben und im Leios-Testnetz Musashi ausführen. Das Modell schreibt eine deklarative Spezifikation (Ketten, Double Spends, konkurrierende Ketten), die Seite prüft sie mit demselben Rust-Code als WebAssembly und zeichnet den UTxO-Graphen. Ein Lauf finanziert das Experiment, signiert jede Transaktion, schickt sie planmäßig an ihr Relay in Frankfurt, Virginia oder Tokio und zeigt, wann sie welchen Mempool erreicht hat und in welchem Block sie gelandet ist. Specs enthalten keine Transaktions-IDs, also läuft ein Experiment auf dem nächsten Node-Build erneut.

Lace Wallet – Event-Driven Indexing Architecture

CQRS Event Sourcing Chain Indexer Bloom Filters TypeScript CIP Authorship Open Source

Authored the event-driven re-architecture behind Lace, Cardano's light wallet: CQRS and event sourcing for indexing the chain and serving wallets, replacing a poll-based backend with a push model. 45% lower latency, 60%+ infrastructure savings, and a custom indexer using bloom filters and credential-based indexing that ingests 2,000+ tx/s for sub-second sync. The design is published as a CIP and a problem statement, so the reasoning is readable rather than asserted.
